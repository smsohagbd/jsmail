User IP Assignments
Assign specific IP pool addresses to users. Assigned users will only send through their designated IPs. All rate limits still apply.

How it works: When a user has one or more IPs assigned, the delivery engine will only use those IPs for that user's outbound mail. All existing rate limits, domain rules, skip-domain rules, IP pool rules, and warmup settings for those IPs continue to apply normally. Users with no assignments share only the IPs that are not assigned to anyone — assigned IPs are fully exclusive. You can assign multiple IPs to a single user for round-robin sending within their dedicated pool.
⚠ Once an IP is assigned it is removed from all other users and from the system shared pool. To re-use it elsewhere you must first remove the assignment.
